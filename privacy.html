Privacy Policy

Last updated: October 3, 2026

lilC (“we”, “the app”) is a local C programming environment for iPhone, with a matching copy in the web browser. You write C in an editor and run it with PicoC, a small interpreter. This page is the public copy of the policy also summarized in Settings.

1. Data we collect

lilC does not require an account and does not collect your name, email, contacts, location, photos, or advertising identifiers. We do not use analytics, crash reporters, or advertising SDKs. These pages do not set cookies or load third-party scripts.

2. Data stored on your device

On iPhone, source files you create are stored in the app’s Documents folder. Theme, editor, and agent preferences are stored in UserDefaults. Agent conversation history and EDSGER teaching chats are stored on the iPhone. In the browser copy, files and theme stay in this browser (IndexedDB / localStorage). With local models, we do not receive those files or conversations. If you choose BYOK cloud models on iPhone, the sharing described below applies.

3. How we use data

Local files are used to let you edit, run, share, and ask the on-device agent to work on programs. EDSGER chat history is used to continue your local learning conversations. Preferences are used to control the app’s appearance and agent mode.

4. Sharing

We do not sell or rent personal data. lilC runs C on-device with PicoC and runs its optional AI agent and EDSGER tutor on-device with a bundled model. Local models do not send your code, questions, or conversations to a cloud AI. On iPhone you may optionally bring an OpenAI or Anthropic (Claude) API key in Settings → BYOK. Before loading or testing a model, you must explicitly allow sharing with that provider. When you select it for Chat or Agent IDE, your prompts, relevant conversation context, imported document passages, project code, and tool results are sent directly from your device to your chosen provider. Your personal API key authenticates those requests with that provider. Edsger’s servers do not receive your BYOK key, prompts or responses. The chosen AI provider processes requests under its policies. Provider retention and abuse-monitoring policies still apply; local-only privacy does not apply to these cloud requests.

Provider policies: OpenAI, Anthropic. We do not sell or rent your data to these providers.

5. Tracking

lilC does not track you across apps or websites. We do not use the App Tracking Transparency prompt because we do not track.

6. Children

lilC is a general-audience coding tool. It is not directed at children under 13. We do not knowingly collect personal information from children.

7. Your choices

You can delete an individual file from Home → Delete and erase local files from Settings. You can turn off Agent Mode in Settings. You can delete EDSGER conversations from its chat history. In BYOK settings you can withdraw provider sharing consent or remove a saved API key. Withdrawal stops new AI requests; it cannot recall data already sent. Removing the key does not revoke it at the provider or erase data already processed there. Revoke keys or request deletion with the provider if needed. Uninstalling lilC removes its local files, agent history, and EDSGER chats from this device. iOS Keychain entries may survive uninstallation; remove your BYOK keys before uninstalling or revoke them with the provider.

8. Security

Programs run in a constrained interpreter. system() is disabled. BYOK keys are stored in the iOS Keychain, accessible only while the device is unlocked, without iCloud synchronization or migration to another device. Keys are not saved in preferences or chat history. Cloud connections use HTTPS, fixed provider destinations and disabled redirects. Do not put API keys or other secrets in prompts, source files, or documents sent to AI. Provider account identifiers and API credentials are processed directly by the selected provider.

9. Purchases

C lessons stay free. The iPhone app may offer a one-time (non-subscription) unlock for an offline Linux study course. Apple processes that purchase. This version of lilC does not sell a subscription. BYOK API usage is billed separately by the provider; consumer ChatGPT or Claude subscriptions do not include API billing. Edsger does not sell API credits or collect provider payments through this feature.

10. Contact

The project is at github.com/garrettmichae1/lilc.

11. Changes

If this policy changes, we will update the date above and the in-app copy.
